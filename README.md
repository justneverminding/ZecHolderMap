# ZecHolderMap
 A privacy-first world map showing where Zcash holders are — without ever revealing who they are.


ZEC Holder Map is an opt-in, anonymous community pulse for the Zcash ecosystem. Holders send a tiny shielded transaction with a memo tagging only their country or continent — never an address or exact location. The map aggregates these coarse signals into a live heatmap so the community can finally see itself: a global footprint that proves where Zcashers are, while proving nothing about any individual. No identity, no tracking, no precise location — just presence, by design.
